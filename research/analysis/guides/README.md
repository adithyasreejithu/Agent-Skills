# Method guides (opt-in)

A guide is the expanded, learner-grade version of a method: all steps, how and why each is used, footnotes to the video evidence, and links to the indicator fact sheet.

**Rule: a guide is made only when the user names the method.** Nothing in the pipeline creates one automatically. The normal method pages in `../methods/` and the master list `../methods.md` are produced for every method as before. The ingest, `analyze` and `--render-only` commands never write to this folder.

## How to request one

Say which method (or methods) to expand, for example: "expand *Market-maker GEX wall read* and *Cash-secured put strike selection*". Each named method gets its own guide in this folder, in the same format as the first.

## The shared indicator sheet

[indicators.md](indicators.md) holds general definitions. It grows only when an expanded method needs a term that is not in it yet. An entry is added then, with a back-link to the step that uses it. Methods that are not expanded add nothing to it.
